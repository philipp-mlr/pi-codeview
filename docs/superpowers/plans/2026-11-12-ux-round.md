**Goal:** Fix everything the impeccable critique (2026-11-12, 22/40) found, in order: long text, fit, trust across worktrees, look, onboarding, then a polish pass. Built directly on `main` (Philipp: "just build on main"); push only after the final review.

**Decisions (approved by Philipp 2026-11-12, "yes sounds great"; scope "everything listed", marks "clearly different"):**
- Floating editor for `pa`, `pn`, `pe`: about 80 columns, wraps, `filetype=markdown`, starts in insert mode; the title says where the text goes, e.g. ` pi ask · session.lua:5 · refactor-discover `. `<C-s>` sends in insert and normal mode, `<CR>` sends in normal mode, `q`/`<Esc>` in normal mode cancels. `pe` prefills the current text. Sending empty text cancels.
- New key `<leader>pk` "peek" (`:PiPeek`): in a checkpoint diff shows the full note and the file's why in a wrapping float; on an annotated line shows the full annotation. Not `K` (that is LSP hover).
- Previews: the note line in the diff shows the first 80 characters then `… <pk>`; annotations show at most 2 wrapped lines then `…`.
- Checkpoint list: `signcolumn=no`, `foldcolumn=0`, `cursorline`; width `max(40, min(60, 35% of columns))`; details wrap to the text width; help line `<CR> open · za more · g? keys`; `g?` shows all keys. Still opens on its own when a checkpoint arrives; `setup({ panel = { auto_open = false } })` turns that off.
- Live marks: `▎` instead of `┃`, `Added`/`Changed`/`Removed` colours; the whole-line highlight is off by default.
- Session picker: named and checkpoint-mode sessions first, rows `name · worktree · state · 5m ago`, no repeated root. "Ago" needs an additive `lastActive` (epoch ms) in the `status` result.
- `pc` with no remarks still continues without asking (approved last round).

## Global Constraints

- nvim 0.12 API; Philipp's setup: nowrap, `signcolumn=yes:1`, gitsigns, LSP, lualine, diffview.nvim, which-key may or may not be installed — never require it.
- Protocol stays version 2; additions only. Default keys never replace existing mappings. All keys under `<leader>p`.
- Every user-visible key hint goes through `keys.label(name, ":Command")`.
- No Nerd Font glyphs; only plain Unicode (`▎ ● ✓ ✗ · … ✎ ⏸`).
- Highlight groups are linked with `default = true` in `highlights.lua` so colourschemes and users can override them; colour never carries meaning alone.
- Each task: TDD (nvim specs in `nvim/tests/*_spec.lua`, vitest in `test/`), README updated where behaviour changes. All three suites green before commit: `npm test`, `npm run typecheck`, `nvim --headless -l nvim/tests/run.lua > /tmp/out 2>&1; echo exit=$?` (check the runner's exit code and that /tmp/out has no FAIL).
- Commits conventional, signed; never `git add -f` under `.superpowers`.

## Review Focus

1. Floating editor: no lost text (closing the window by `:q`, `<C-w>c`, or leaving it cancels cleanly, no stray buffers); works when invoked from a diff tab, the panel, a visual selection.
2. Everything fits at 80, 120 and 200 columns with `signcolumn=yes:1`; nothing writes past the window edge.
3. Session naming in sends is right when the buffer's worktree differs from the attached one.
4. Old extensions without `lastActive` still work in the picker.
